# Datos

El dataset de trabajo **no se publica en GitHub**.

Archivo esperado por el proyecto:

`radiomica_pancreas_dataset_semana3.csv`

Motivo: el repositorio es público y los datos del proyecto deben mantenerse fuera del control de versiones. El script recibe la ruta mediante `--data`.

Ejemplo:

```bash
python src/run_experiment.py --data /ruta/radiomica_pancreas_dataset_semana3.csv --output results/run
```
